## ⚡ Quick Start

### 1. Run Backend Service
```bash
cd vex-project/backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn src.main:app --reload --port 8000
```

### 2. Run Frontend Dashboard
```bash
cd vex-project
npm install
npm run dev
```
