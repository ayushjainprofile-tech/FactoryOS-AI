# Vex Multi-Cloud Deployment Guide

This directory houses cloud provider metadata and deployment descriptors.

## Subdirectories
- `aws/`: ECS Task Definitions for AWS Fargate.
- `azure/`: Container App deployment configurations.
- `railway/`: Railway service mapping keys.
- `render/`: Render Blueprint infrastructure specification.
- `k8s/` and `helm/`: Deployment manifests for Kubernetes clusters.
